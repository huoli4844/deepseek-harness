# 人力投入分析

## 适用范围

员工要求生成月度人力投入分析时使用。首版唯一产物是一份由元枢工作台生成的固定模板 Excel，其中同时呈现项目投入、人资工作项、分析结论和复算依据；只填写获授权且有依据的数值与结论。不生成 A2UI 报告界面或单独的预览文件。是否能够交付，以工作台当前已上线的能力与本人授权为准。

首版 Excel 的业务内容、工作表顺序和复核要求见[输出内容定义](references/输出内容定义.md)。该定义需经人力组确认，并由工作台落实为版本化模板后，才能称为正式交付。相同模板版本每次使用相同的工作表、列名、顺序、单位和计算口径；没有数据的项目保留状态与空值，不临时删列或填零。

## 分析流程

1. 确认统计月份、租户、组织与人员范围。缺少关键范围时请本人补充，不自行扩大到全公司或其他月份。沿用工作台已核定的口径与模板版本；口径尚未核定时说明待定，停止生成文件。
2. 在读取、分析和导出前，分别核对当前员工的权限与数据范围。首版完整 Excel 只交付获授权的人力组人员；部门负责人、员工本人和管理层的其他视图须另有已核定的独立版本和授权，不能从完整文件删列代替。权限拒绝或暂时无法核实时停止相应动作。
3. 核对本期人员与项目范围、周报及其他已授权工作依据、法定工作日历和薪资数据的覆盖情况。人员范围须考虑入转调离与在职区间。说明数据截止时间、缺报窗口、缺少的人员或月份与覆盖度。没有数据、来源失败和未获授权要分别说明。未覆盖窗口不推算工时；覆盖度不足时保留明显提示，不能标成完整月度结果。
4. 查看工作台给出的项目或职能工作项分类建议、依据和置信度。对低置信度、跨项目、空白周报、加班或稀薄内容等争议项交由有权限的人员逐项复核。一个人一个月可以拆分到多项；每次人工调整都要确认归属、理由和记录人。职能工作项还要核对相应产出依据。没有足够依据时标为待核，不猜测权重或工作成果。
5. 由工作台按本期已核定的规则计算工时、分摊金额和指标，并将争议项交给获授权的复核人处理。分摊金额是按工时归集的金额，不代表实付薪酬。跨月周窗口、调休、加班和人工调整均以当前规则版本处理；不得在对话中临时改口径或手算替代正式结果。比较分摊金额与时薪指数时，说明两者使用的月份口径可能不同。
6. 按输出内容定义检查各工作表及其固定分析面、分类后的各项合计、人员合计与总体合计，确认覆盖度提示和异常提醒已呈现。核对申报缺口、负荷突变、连续无项目工时和事务占比异动；无法对账、必需数据缺失、规则冲突或仍有必审项时，保留待处理状态并说明原因，不交付标为已核定的 Excel。
7. 必审项处理完且对账通过后，请获授权的复核人确认统计范围和生成请求。等待工作台完成生成并返回成功结果，再提供唯一的 Excel 文件。文件应符合已确认的输出内容定义，并标明统计范围、数据截止时间、覆盖度、规则与模板版本。导出失败或结果未知时先核对任务状态，不能宣称成功或重复发起可能产生多份结果的操作。

## 结果使用

- 向员工说明已核定 Excel 的统计月份、组织和人员范围、覆盖情况及口径；只提供提问者有权取得的文件。数据不足或复核未完成时只反馈状态与待处理原因，不生成文件；不作缺乏依据的绩效判断。
- 已配置的月度任务在工作台报告结果后检查状态；数据源为空或运行失败时展示失败状态和原因，不静默跳过。未配置月度任务时只处理员工发起的分析，不声称已自动运行或已推送其他交付物。
- 仅使用任务、审批、文档、工时等获授权的工作依据；不采集在线时长、屏幕行为、聊天内容或位置。分析用于工作量与流程改进；用于个人评价须另行确认授权和适用规则。
- 若工作台尚未提供某项取数、复核、计算或导出能力，说明当前停在哪一步和缺少的能力，不把普通业务查询结果当作已核定月度分析，也不自行拼装正式 Excel。
