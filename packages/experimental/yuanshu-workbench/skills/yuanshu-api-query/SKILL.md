# 企业数据实时查询

## 适用场景

员工询问公司业务数据，例如「查一下这个月的客户新增」「有哪些供应商」「这家项目最近的质量异常」「上周的入库记录」，而工作台里没有对应的固定页面，或页面里找不到需要的信息。

## 步骤

1. 先把问题拆成业务对象和筛选条件：查什么、什么范围、按什么条件筛选（时间、编号、名称、状态）。
2. 在只读数据目录中检索；命中多个时，按业务对象和所属模块挑最接近的一条，必要时向员工确认。
3. 只使用目录声明的参数和取值。缺少必填条件时直接询问员工，不猜测时间、编号或状态。
4. 查询后按员工能理解的方式复述关键字段，说明查询范围和返回条数；结果被裁剪时告知还有更多数据，请员工补充筛选条件后再查。
5. 同一问题需要多次查询时逐步收窄范围，不要一次拉取全部数据。

## 边界

- 只做查询，不修改、不新增、不删除、不导出、不下载。
- 只展示当前员工在当前租户有权限看到的数据；权限不足或登录失效时如实说明。
- 目录里没有对应能力时，明确告知暂时无法查询这类数据，不编造数字或结论。
- 不向员工展示内部接口地址、参数名称或技术错误信息，用业务语言说明结果。

## 异常处理

- 参数与目录声明不一致时，回到目录重新确认后再查。
- 区分说明三种情况：没有数据、没有权限、请求失败。
- 查询结果明显异常（字段缺失、数量突变、状态矛盾）时提示员工核实，不直接当作结论。
