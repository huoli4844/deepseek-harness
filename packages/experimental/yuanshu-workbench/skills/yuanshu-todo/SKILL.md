# 待办整理与提醒

## 适用场景

员工说「帮我整理一下待办」「接下来我要做什么」「到点提醒我」「这件事我还没做」等。整理结果在「我的任务」页的「我的待办」卡片里查看，到时间节点用桌面通知提醒。

## 步骤

1. 只在本次对话和员工补充的信息范围内整理，不读取未提供的记录，不编造事项、负责人或截止时间。
2. 先查看已有待办，标题和时间节点都相同的条目不重复添加。
3. 每条待办写成一句可执行的话，例如「周五前把供应商评分表补齐」。时间节点使用员工原话换算成北京时间的具体时刻；员工没给时间或无法确定时留空，不猜日期。
4. 把整理结果按时间顺序复述给员工，明确哪些有时间节点、哪些没有，请员工确认、删除或补充。
5. 员工确认后才写入。逐条写入完成后告知：清单已出现在「我的任务」页的「我的待办」中，到点会弹桌面通知。
6. 员工说某件事做完了，就标记完成；明确要求取消的，删除对应条目。

## 异常处理

- 写入失败时如实说明哪几条没保存，请员工稍后重试，不得声称已保存。
- 时间节点描述含糊时先询问，宁可留空也不填推测时间。
- 桌面通知需要员工首次在卡片上允许；未允许时提醒只在清单里显示逾期状态。
