# 创建自定义页面

1. 员工在工作台对话里提出创建个人页面。打开对话内的页面草稿，并预填员工已给出的名称和时间范围。首个可选页面展示本人在所选项目的工时，可选择本周或本月作为默认范围。以工作台提供的项目和实际查询结果为准。
2. 请员工在「页面名称」中输入或编辑名称，然后打开预览。预览中的「页面切换按钮」显示即将注册的名称。请员工核对这个名称、项目和时间范围，需修改时先返回编辑，再重新预览。
3. 由员工本人点击「确认名称并发布」。取消时结束本次发布。只有工作台发布成功并显示对应按钮后，才告知员工已注册。名称重复时，请员工返回编辑并确认新名称。
4. 下次登录同一客户端时，从「我的个人页」顶部点选该名称。切换或重新打开页面时，工作台按当时的权限和筛选查询最新业务数据。本周和本月以打开时的日期计算。查询失败或权限变化时，以工作台提示为准。
