# 创建自定义页面

1. 员工在工作台对话里提出创建个人页面，说明想看的数据。打开对话内的页面草稿，并预填员工已给出的名称。页面由一张或多张数据卡片自由组装，内容不限定：员工没有明确指定卡片构成时，先按想看的内容挑选或组合卡片，不要只给默认工时卡。
2. 卡片构成方式：
   - 固定卡片：`labor-month`（本人项目工时，period 用 week 或 month）、`member-labor`（指定成员的已批准工时，需 memberId）、`headcount`（本租户人员概览统计）。
   - 数据卡片 `data-query`：可以展示任意业务数据。先调用 `yuanshu_api_search` 按业务对象检索只读数据目录，挑选最贴合的 GET 接口；把目录里的 `path`（保留 `{参数}` 占位符）与必填参数写入卡片配置，并用中文业务含义命名 `title`。按数据含义选择 `view` 展示形式：关键指标用 `stats`（数字统计卡，`columns` 指定要聚合的数值字段，并用 `aggregate` 选择聚合方式：sum 求和 / avg 平均 / max 最大 / min 最小 / count 记录总数）、项目/人员对比排名用 `bar`（条形图，`columns` 给出名称字段 + 数值字段）、明细清单用 `table`。返回记录较多时用 `columns` 选出最相关的字段（不超过 8 个）。**必须用 `labels` 给卡片涉及的字段配中文标签**（如 {"progress_percent":"进度","manager_name":"负责人"}），员工界面不显示英文表头。参数取值不确定时先向员工确认（如项目编码要先问清是哪个项目）。
   - 多项目综合统计（管理层/CEO 视角）：优先用**跨项目列表接口**（如项目列表、采购台账、能力合同等不带 `{参数}` 占位符的接口）+ `stats` 卡聚合（count 项目总数、avg 平均进度、sum 合同金额/已付金额/成本），每张统计卡只表达一个口径，并列排成指标行；单项目财务明细（合同、成本、付款申请、发票都在 `/apps/shaoshi/projects/{code}/…` 下）需要项目编码，一张卡对应一个项目，重点项目多时先问员工要哪几个编码，不要一次铺十几张卡。跨项目口径与单项目口径分开放置，卡片 `title` 写清口径（如「全部项目合同额」「XX 项目已付金额」）。
   - 通过 `personal_pages_open_draft` 的 `widgets` 参数一次性预填全部卡片；不传 widgets 时默认生成一张本月工时卡。
3. 请员工在弹窗中核对名称与各卡片的实际数据，可增删卡片后重新预览。预览中每张卡片都会实时查询真实数据，加载失败或为空时先检查接口选择与参数，再重新预览。
4. 由员工本人点击「确认名称并发布」。取消时结束本次发布。只有工作台发布成功并显示对应按钮后，才告知员工已注册。名称重复时，请员工返回编辑并确认新名称。
5. 下次登录同一客户端时，从「我的个人页」顶部点选该名称。切换或重新打开页面时，工作台按当时的权限和筛选查询最新业务数据。本周和本月以打开时的日期计算。查询失败或权限变化时，以工作台提示为准。
