# 业务表单办理

工作台明确返回可联调预览时，可用测试资料走预填、编辑、校验和模拟保存。预览不代表获得业务权限，模拟完成后说明没有写入业务数据。正式办理仍按以下流程验权。

查询、导出、新建、编辑、保存、删除、提交和审批等访问或改变企业数据的操作，都先核对当前员工在所选租户的具体动作权限和数据范围。涉及多项操作时逐项核对。通过后才继续执行对应流程。以下是适用表单的办理步骤。每次办理都以工作台当前提供的动作定义、员工授权结果和字段定义为准。同一技能适用于后台目录新发布的业务对象。

复核弹窗使用工作台的标准表单布局和组件，跟随当前界面的主题、字体和字号设置。

1. 结合当前消息和同一对话里最近一轮明确的事项，识别具体业务对象和动作。保留员工指定的业务类型。如涉及编辑，先识别员工指的是哪项业务。「就按这个建」「按上面来」「帮我保存」可继续同一事项。
2. 每次发起或继续办理时，先让工作台从当前服务目录匹配目标动作，核对当前员工在所选租户的操作权限及数据范围，并获取经工作台校验的字段定义。没有权限或暂时无法核实时，说明原因并结束本次办理。权限确认后才继续查找记录、准备资料、下载模板或打开表单。编辑时由本人确认要修改的记录。缺少可执行动作、字段或回执规则时，说明具体缺项并保留已收集的内容。只校验已明确声明的必填项。未声明必填项时可正常复核和确认提交，按后台的校验提示补填。
3. 按工作台给出的可编辑字段、类型、必填项和允许值准备资料。没有资料时，提供工作台支持的模板下载、上传或文字描述方式。上传时由工作台校验列名、必填值、类型、枚举和表内重复，并按业务规则查重。提示问题所在的行和字段。
4. 请工作台用通用 A2UI 能力根据当前动作的字段定义生成复核表单，或继续使用该事项已打开的表单。预填员工明确提供的资料。编辑时展示原记录和拟修改的内容。把「可选」「待补」等占位留空，标出缺少的必填项。固定选项显示中文下拉框，能唯一匹配时预选，否则请本人选择。保存时由工作台按选项的原值和原类型提交。
5. 本人在表单中完成编辑并点击确认后，由工作台用当前员工和租户的身份执行对应操作。取消时结束办理。保存期间等待回执并避免重复点击。确认成功后展示结果，由本人确认关闭。
6. 后台明确拒绝时，在原表单显示原因，保留已填内容供修改。批量中已保存的行保留结果。回执不明确时先核对台账，确认结果后再继续。
