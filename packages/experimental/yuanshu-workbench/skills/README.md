# 工作台业务技能

- 命令 `/yuanshu-work-report` 加载工作报告技能。在对话中也可以说「写日报」「写周报」或「写项目周报」。新建前先查询本人本期报告，项目周报按项目确认范围并逐项复核保存。[工作报告](yuanshu-work-report/SKILL.md)
- 命令 `/yuanshu-business-record-create` 加载新建业务表单技能。在对话中也可以说「新建设备」或「新建入职任务」，下载模板、上传表格或描述内容，核对后保存。[新建业务表单](yuanshu-business-record-create/SKILL.md)
- 命令 `/yuanshu-business-capabilities` 查询指定业务能否新增、需准备哪些资料。也可以问「现在能新增项目合同吗」。[查询业务能力](yuanshu-business-capabilities/SKILL.md)

- 命令 `/yuanshu-custom-page-create` 加载创建自定义页面技能，指引员工预览、确认名称并发布到「我的个人页」。[创建自定义页面](yuanshu-custom-page-create/SKILL.md)

新增技能时遵循[开发规则](AGENTS.md)，并更新[技能包总览](技能包总览.md)。
