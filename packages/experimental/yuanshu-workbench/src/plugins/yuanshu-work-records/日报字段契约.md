# 日报字段契约

数据表为 `public.tsk_daily_work_reports`。字段及约束来自后台迁移 `0009_daily_work_reports.sql`、日报领域模型和 API。工作日期按北京时间，同一租户和员工每天一份。

| 字段 | 类型 | 定义与取值 |
| --- | --- | --- |
| `id` | bigint | 数据库生成的主键 |
| `business_tenant_id` | bigint | 正整数，由可信身份确定 |
| `user_id` | bigint | 正整数，由可信身份确定 |
| `work_date` | date | 工作日期，按北京时间确定 |
| `completed_work` | text | 已完成工作，最多 10000 字符，默认空串 |
| `in_progress_work` | text | 进行中工作，最多 10000 字符，默认空串 |
| `planned_work` | text | 后续计划，最多 10000 字符，默认空串 |
| `issues_and_risks` | text | 问题与风险，最多 10000 字符，默认空串表示未填 |
| `need_support` | text | 协调支持，最多 10000 字符，默认空串 |
| `evidence_refs` | jsonb | 最多 100 条依据引用，含会话标识和非负序号，默认空数组 |
| `status` | varchar(20) | `draft` 草稿（默认），`submitted` 已提交并锁定 |
| `version` | bigint | 正整数，初始值为 1，每次有效保存递增 |
| `last_request_id` | uuid | 最近一次人工确认的请求标识，用于幂等核验 |
| `last_request_hash` | varchar(64) | 最近一次请求的 SHA-256 摘要 |
| `submitted_at` | timestamptz | 成功提交时写入，NULL 表示未提交 |
| `created_at` | timestamptz | 首次保存时间，默认当前时间 |
| `updated_at` | timestamptz | 最近一次有效保存时间，默认当前时间 |

表单编辑范围为五个正文字段。提交时已完成工作和进行中工作至少有一项非空。恢复请求沿用原工作日期，请求结果未知时保留原正文、依据、版本和请求标识。
