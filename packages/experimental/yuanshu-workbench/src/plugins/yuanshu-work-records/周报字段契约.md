# 周报字段契约

数据表为 `public.prj_project_weekly_reports`。字段及约束来自后台迁移 `0002_project_weekly_reports.sql`、`0007_standardize_comments.sql`、`0008_weekly_report_user_week.sql` 和现行 OpenAPI。每个租户的每位员工每自然周一份。

| 字段 | 类型 | 定义与取值 |
| --- | --- | --- |
| `id` | bigint | 数据库生成的主键 |
| `business_tenant_id` | bigint | 所属租户，由可信身份确定 |
| `period_start` | date | 北京时间自然周周一 |
| `period_end` | date | 同一自然周周日，由开始日期加六天确定 |
| `progress_summary` | text | 本周进展摘要，提交时必填 |
| `completed_work` | text | 完成工作。弹窗写入编码后的事项数组，提交时至少一条完整事项 |
| `planned_work` | text | 下周工作计划，提交时必填 |
| `issues_and_risks` | text | 问题与风险，NULL 表示未填 |
| `need_support` | text | 需要协调与支持，NULL 表示未填 |
| `status` | varchar(20) | `draft` 草稿（默认），`submitted` 已提交并锁定 |
| `created_by` | bigint | 创建人的元枢用户 ID，由可信身份确定 |
| `submitted_by` | bigint | 提交人的元枢用户 ID，NULL 表示未提交 |
| `submitted_at` | timestamptz | 成功提交时写入，NULL 表示未提交 |
| `created_at` | timestamptz | 首次保存时间，默认当前时间 |
| `updated_at` | timestamptz | 最近一次有效保存或提交时间，默认当前时间 |

事项最多 200 条。以下字段依据后台 OpenAPI 的 `WeeklyReportDraftItem` 和 `WeeklyReportItem`。非空项目编码须属于当前租户。

| 事项字段 | 类型 | 定义与取值 |
| --- | --- | --- |
| `project_code` | string | 1 至 64 个字符，首字符为数字或英文字母，其余还可使用点、下划线、连字符。草稿可留空 |
| `work_type` | string | `direct` 直接工时、`indirect` 间接工时、`meeting` 会议、`overtime` 加班、`training` 培训。草稿可留空 |
| `description` | string | 事项说明，后台最多 10000 字符，弹窗最多 2000 字符。草稿可留空 |
| `completion_status` | string | `pending` 待处理、`in_progress` 进行中、`completed` 已完成、`blocked` 已阻塞、`cancelled` 已取消。草稿可留空 |
| `has_risk` | boolean | true 有风险，false 无风险 |
| `risk_details` | string 或 null | 风险说明，后台最多 10000 字符，弹窗最多 2000 字符。NULL 表示未填写或无风险 |

项目名称来自项目主数据。恢复时使用初次打开表单所见的草稿更新时间校验冲突，已提交记录需核对实际正文。
