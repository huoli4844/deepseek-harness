# @deepseek-ai/dsh-yuanshu-workbench

[English](README.md) | 中文

## 概述

此组合包在 DSH Web 中提供岗位助理收件页、岗位图表、项目运营、工作群和日程操作。18 个岗位与公司管理层包含 KPI 场景和日常工作方法。图表与协作记录仍是浏览器本地演示数据。配置员工 MCP 后，DSH 原生助理可以发现获准使用的元枢工具。「我的任务」和「日程日历」通过 DSH Host 代理调用元枢认证 REST API，并跟随 `.env` 中的本机或远程 API 地址。

## 使用此包

### 连接员工账号

在单账号 DSH Host 的 `yuanshu-workbench` 插件条目配置 `mcp.url` 和 `mcp.clientId`。在元枢注册 DSH 的准确来源地址加 `/mcp/oauth/callback/56a411dab576919cbca52fcfee03f1a34ff9b37d4858c71c781c9005942ac59f` 作为回调，并在元枢的 `client_mcp.preauthorized_clients` 中按租户 ID 加入该客户端 ID。打开插件页 → 元枢工作台 → 登录元枢。浏览器登录成功后，获预授权的客户端直接取得读取权限。其他客户端继续走显式同意流程。当前授权页只支持无需额外完成 MFA 或验证码挑战的登录。

在当前检出目录开发时，将仓库根目录的 `.env.example` 复制为 `.env`。Web 登录服务、工作台 MCP 客户端和业务数据代理都使用 `YUANSHU_REMOTE_API_URL`、`YUANSHU_REMOTE_MCP_URL` 配置的元枢云服务。`YUANSHU_MCP_STARTUP_TIMEOUT_MS` 单独限制每次 MCP 连接尝试和初次工具发现的时长，不影响 API 与工具调用请求；默认值为 `30000` 毫秒，`requestTimeoutMs` 默认值为 `90000` 毫秒。

连接模式下，「今日工作」「岗位工作台」「项目运营」「经营重点」和「工作方法」继续使用员工 MCP 投影。「我的任务」和「日程日历」通过 Host 代理读取并写入元枢个人任务、日历和日程 REST 资源。消息通知并入待办事项页展示；工作群和文件与资料在接入平台数据源前显示未接入提示。

个人资料通过宿主调用 `GET /api/v1/user-positions?user_id=…` 读取本人任职，并显示当前岗位描述。任职记录未附带描述时，通过 `GET /api/v1/positions/all` 按岗位 ID 匹配。用户权限区支持按名称或编码筛选已加载的权限目录，保留命中项的上级分组。

同一业务表单技能可为有项目写入权限的员工打开新建项目表单。填写项目编码和名称后，保存时核对编码，并以员工在当前租户的身份调用 `POST /api/v1/apps/shaoshi/projects`。回执仅含主键或成功码时，工作台按项目编码回查后再报告成功。

### 从当前检出目录预览

构建当前检出版本后，在 `dev` 分支的仓库根目录启动 Web profile。源码启动器先加入工作台组合包，再应用你的 Web profile 补丁。

```sh
pnpm run build
pnpm dsh web
```

打开 DSH 输出的本地入口地址。插件加载后进入**元枢工作台**的**今日工作**页，仅显示工作台自己的导航和内容。收件页汇集岗位关注、本人任务和日程；**岗位工作台**用于查看图表和比较。通过工作台底部按钮返回 DSH 原始界面，当前会话保持选中。演示记录保存在当前浏览器 profile 中，页面刷新或插件重新加载后仍会保留；清除站点数据会删除这些记录。

右侧对话区的工作区切换控件位于输入框右上方，并与输入区右侧对齐。菜单向上展开，支持切换工作区、打开其中的会话和新建工作区。

合同管理默认按项目显示卡片组，支持通过宿主搜索和切换合同列表，展示项目财务汇总及合同明细。毛利数据取云端项目财务汇总，整体毛利率按项目收入加权；缺失金额保持不可用。各页面统计卡片的标签与数值统一居中。

### 员工日报场景

适用于需要登记本人日报的技术、管理及其他员工岗位。技能包只写业务流程，内部工具绑定、接口契约和后台访问归宿主插件。设备登记能力说明见[新建业务表单技能](skills/yuanshu-business-record-create/SKILL.md)，实现及权限边界见[日报场景实现](docs/work-records.md)，技术资料不放在技能包内。

只读取当前账号已验证、活跃的工作台会话与本人日报，不查询其他员工日报或公司经营汇总。弹窗绑定 `edit.v1` 固定模板，焦点进入首个可编辑字段，标题和页脚固定，正文滚动。已有草稿保留人工正文；本人点击保存或提交才写后台。

| 后台方法与路径 | 范围与动作 |
| --- | --- |
| `GET /api/v1/apps/deepseek-harness/daily-reports/schema` | 可信本人、当前租户和授权日报字段 |
| `GET /api/v1/apps/deepseek-harness/daily-reports/{date}` | 本人指定工作日的日报 |
| `PUT /api/v1/apps/deepseek-harness/daily-reports/{date}` | 人工确认最终正文，保存或原子提交 |

客户端通过同源 `/yuanshu-workbench/daily-report-runtime` 业务路由调用，宿主使用当前员工身份访问配置的本地业务服务。插件及技能脚本均不直连业务数据库。

正常验收：整理只打开预填弹窗，人工修改并确认后才保存最终正文。受限验收：不同用户或租户无法认领已有会话；已提交日报无法编辑；结果未知时仅原请求重试，不提示未经确认的成功。正式使用前由维护流程执行 `0009_daily_work_reports.sql`，启动不自动迁移。

### 可体验的功能

在「工时填报」选择项目后查看或更新工时。在「周报管理/登记」选择项目和北京时间自然周，保存草稿或提交锁定。已批准工时汇总可跳转至同项目、同周的明细。保存和提交需要可信元枢网关身份，周报服务还需要先执行数据库迁移。

客户资源和供应商管理表在横向滚动时将操作列固定在右侧。两张表的审计时间按北京时间（`Asia/Shanghai`）显示。

提交客户或供应商的筛选条件后查询业务后台。供应商分类选项来自当前租户。点击数据列表头后，后台对全部匹配结果排序并分页。档案总数位于分页组件之前，分页显示匹配结果的页数。桌面开发版将档案请求诊断写入启动日志。

在项目运营页展开 ECN-204，点击「准备 DSH 分析草稿」。演示资料和补充约束会加入当前或最近工作区的新会话草稿。检查草稿后即可发送，标准 DSH 会话会显示实际创建的子智能体。

在 **项目经理 → 今日工作** 中打开延期预警，演练 MS-017：生成模拟分析、批准建议方案、模拟派发、验收模拟回执。关闭后可在跟踪区回看决策记录。预警、证据编号和允许的状态转换由里程碑模拟模块提供；接入平台时改用经过授权的读取接口与业务命令。

- 普通岗位提供 6 张图表，公司管理层与特种车业务总裁提供 8 张：趋势、进度、业务分布、计划对比、每周完成量和风险矩阵；管理层另含回款和资源覆盖率。新增图表可打开数据明细并进入关联任务。
- 切换全部 19 个岗位视角：助理收件页和岗位图表会随岗位适配，公共导航始终可用。公司管理层与特种车业务总裁可从风险汇总进入责任岗位。
- 查看公司重点事项的演示值、来源、责任岗位和下一步行动；默认显示当前岗位承担的事项，也可切换到公司清单并进入对应 KPI 工作流。
- 启动本地助理流程演示：查看四步计划、来源与 KPI 依据、跨岗位复核、可编辑建议和人工确认；确认后只更新关联的浏览器本地演示工作项。
- 在浏览器 profile 中保存岗位专属的助理偏好，并在每次运行时与方法、来源依据和拟议行动并列查看。
- 打开岗位的任一 KPI 关联场景，助理会进入其典型工作，套用对应岗位方法并准备待复核草稿；每个岗位另有 3 项高频工作场景，以可视四步 SOP 流程呈现并可直接交由助理协同开展。
- 「今日工作」先呈现助理建议优先处理的事项及原因，再列出其他待决定、待复核和收到的交付。操作可直达对应 SOP、群内交付要求或具体项目记录。展开常用工作场景可查看启动条件和交付要求。等待协作、已完成记录及 KPI 场景可在下方查看。
- 从「今日工作」继续上次的工作：切换页面或刷新当前浏览器 profile 后，仍可恢复岗位视角、SOP 步骤、草稿材料和交接摘要。
- 全部 57 项岗位工作配置建议方法，以及各自的材料、交付物和验收关注点。材料、分析、成果和审阅阶段内嵌方法指导、证据记录与自查项；版本保存方法执行快照。方法库直接打开对应任务。
- 打开任务、编辑建议、保存版本，并从任务内打开版本历史、比较快照、采纳预设建议和模拟审阅交接。
- 选择日历日期并添加本地日程；切换岗位后，日程和消息已读状态仍保留。
- 创建项目沟通、工作督办或专题讨论群，邀请岗位助理，发布工作安排、发送本地消息并回看群历史。受派岗位先提交交付记录，再由工作负责人打开关联任务复核。助理回复为脚本演示。
- 打开项目运营台选择项目，检查关联里程碑和依赖，查看带证据的变化与风险，记录决策方案，完成责任行动，并在必要行动验证后提交验收。
- 从助理提醒或岗位工作台进入岗位运营。其余 17 个岗位及公司管理层各有业务来源、指标对比、两种处置方案及关联 SOP。确认方案后创建工作群派单，切换至交付岗位可在助理待办中提交证据，再切回发起岗位按场景标准退回补充或记录验收。群内保留派单、证据与复核记录。
- 在文件与资料页查看演示材料，并在工作群分别跟踪任务安排、岗位交付和负责人复核。
- 在对话中直接问公司业务数据（客户、供应商、项目、质量等）：助手先在只读接口目录里检索，再用当前员工身份和租户实时查询，结果按条数裁剪；目录里没有对应能力时如实说明。只读，不修改、不导出。

## 模型体验

对话注册两个宿主工具：`yuanshu_api_search` 在构建期生成的只读接口目录（当前 894 个 GET 接口）中按业务词检索，返回路径、说明与参数；`yuanshu_api_query` 按目录路径以当前员工凭证和主动租户查询，并裁剪条数与输出长度。工具声明和目录在插件启用时固定；员工令牌只在宿主内使用，不进入模型上下文或工具结果。目录由 [生成脚本](scripts/generate-api-catalog.mjs) 从 Swagger 快照生成，接口变化后重跑即可。

#### KV 缓存影响

工作台导航与草稿编辑不改变模型请求及其缓存。查询工具的参数在会话内按需传入，不改变工具声明本身。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 岗位选择仅演示界面适配，不授予身份或业务权限。公司管理层是额外演示视角，没有在平台岗位表中新增岗位；项目管理尚未配置 KPI，其图表仅展示演示进度。
- 图表数值、资料和日程日期均为合成演示内容，不是已确认的 KPI 公式或实时经营结果。
- 交接和通知仅在本地模拟，不发送外部消息，也不创建平台任务或审批。工作群成员、安排和聊天记录保存在当前浏览器 profile。
- 助理计划、岗位交付记录和审批结果均为脚本演示，不调用模型或 MCP 工具；交付不会创建或更新平台数据。
- 岗位偏好是浏览器本地的原型上下文，不会发送给模型或元枢平台。
- 16 种建议方法需经业务确认后才能成为正式规程。自查只记录用户确认；未完成的事项可携带可见缺口提交协同审阅，不会自动通过审批。
- 演示记录仅保存在当前浏览器 profile，不会跨设备同步，也不是元枢业务记录。元枢 MCP 集成与业务状态持久化不属于此原型范围。

### 开发备注

<details>
<summary>维护者工作上下文——点击展开</summary>

此包是 `dev` 分支上的实验性插件原型，用于在平台集成前评审界面。

启用真实工作台时，为工作台 MCP 配置员工端点、OAuth 客户端 ID 和元枢云服务 API 地址（`apiUrl`）。Host 核实当前登录员工和租户后读取工作台数据。只有已验证的员工与租户 ID 会保留到 profile 过期或 MCP 连接代次变化；工作台投影使用元枢授权。业务数据代理以及「我的任务」「日程日历」的 REST 请求统一使用 `YUANSHU_REMOTE_API_URL` 指向的云服务。在元枢的 `client_mcp.preauthorized_clients` 中为需要自动连接的租户登记 DSH 客户端。登录后打开「今日工作」时，DSH 会为所选租户申请只读授权。

在元枢 OAuth 客户端登记 DSH 的完整回调地址。Host 对外地址为 `http://127.0.0.1:3080` 时，回调地址是 `http://127.0.0.1:3080/mcp/oauth/callback/56a411dab576919cbca52fcfee03f1a34ff9b37d4858c71c781c9005942ac59f`。

### 日报和周报回执

日报和周报共用[工作报告技能](skills/yuanshu-work-report/SKILL.md)。员工在对话中指定写日报或周报即可选择对应流程。

日报和周报字段的类型、取值和约束见工作记录插件内的[日报字段契约](src/plugins/yuanshu-work-records/日报字段契约.md)和[周报字段契约](src/plugins/yuanshu-work-records/周报字段契约.md)。

「待办事项」中的「报表回执与待办」按当前企业账号展示本机操作结果。失败项可打开原表单继续处理。后台明确拒绝时可修改后再次提交，提交结果未知时需先原样核对上次请求。收到后台确认后，待办更新为成功回执。记录保存在发起操作的设备上。

### 设备登记与服务目录

设备工程师及获授权员工可从设备台账或[新建业务表单技能](skills/yuanshu-business-record-create/SKILL.md)打开复核表单。有权限的人事员工也可用该技能登记入职任务。表单可下载 UTF-8 CSV 模板和导入 CSV/TSV。查重使用当前租户的设备查询接口，按编码和出厂编号匹配；新增使用同一设备资源的 POST，由云端再次鉴权并校验编码唯一性。用户保存后逐条写入，已成功的行不会重复提交，失败行仍可核对和编辑。网络中断或回执不明确时，应先检查台账。实现及权限边界见[日报场景实现](docs/work-records.md)。

有客户写入权限的员工也可使用同一技能登记客户。确认按对话里的资料新建后，工作台打开预填复核表单。保存时按客户编码与当前租户的客户列表核对重复，并使用员工权限调用云端客户新增接口（`POST /api/v1/apps/shaoshi/customers`）。后台明确拒绝时，表单保留输入供员工修改。

同一技能可根据对话资料登记项目销售合同草稿。表单核对当前租户内的项目和客户后，通过 `POST /api/v1/apps/shaoshi/projects/{code}/contracts` 保存，由云端校验写入权限。云端接口不接收自定义合同编号，接受服务端编号时才清空拟定编号。成功回执展示核实后的合同编号。

工作台在登录后通过已授权的 MCP 连接刷新服务工具目录。后台接口报错时，五分钟内复用最近一次成功目录；过期后合并并发请求，刷新失败也限制重试频率。刷新目录不会重发原业务请求，也不改变云端接口的权限。

登录后，宿主并行读取云端 Swagger 服务目录、员工在所选租户下的角色与有效权限，并在已授权的 MCP 连接就绪后刷新工具目录。智能体可在绑定员工账号的会话里按关键词查询 Swagger 操作及核对员工权限。Swagger 目录用于发现接口，保存需要相应的工作台动作，由后台逐次鉴权。
