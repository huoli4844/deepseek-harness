# 元枢人力投入分析智能体

版本：业务定义草案 1.0。状态：开发定义已建立，Agent preset、专用分析插件和正式 Excel 模板尚未实现，当前不可安装或运行完整分析。

## 定位与触发

面向获授权的人力组人员，按指定月份和组织范围，将元枢后台已授权的人员、周报或工时、薪资、项目及职能工作依据，归集为可复算的人力投入分析。员工在元枢工作台提出「生成上月人力投入分析」「统计某月项目分摊与人资工作结构」等请求时进入该流程。首版以按需生成一份 Excel 为目标。

## 输入与唯一产物

- 输入：当前租户与员工身份、统计月份、组织和人员范围、已核定的工作日历、分类与调整规则、元枢后台可用的数据快照。缺少月份或范围时先由发起人确认。
- 唯一产物：一份固定版本 Excel。前六张工作表承载总览、覆盖度与口径、项目结构、个人明细、负荷与效率、管理建议；后六张承载分摊明细、异常与复核、人资工作结构、人资指标、人资过程明细、数据来源与缺口。
- 输出的业务列、顺序、计算来源和历史回归条件维护在[Excel 输出内容定义](../../skills/yuanshu-hr-analysis/references/输出内容定义.md)。该定义须经人力组确认；正式可执行模板及字段版本由后续分析插件维护，并与此定义同步。文件记录数据快照、规则版本、模板版本、统计范围和覆盖度。

## 必需技能与插件

| 依赖 | 提供方 | 当前状态 | 用途 |
| --- | --- | --- | --- |
| `yuanshu-hr-analysis` 员工技能 | 元枢工作台插件 `@deepseek-ai/dsh-yuanshu-workbench` | 技能文件与宿主注册已建立；工作台启用员工连接后才可发现 | 约束月度分析、人工复核与 Excel 交付流程。 |
| 人力分析专用能力 | 待开发的人力分析业务插件及元枢后台 | 尚未发布 | 提供授权数据快照、分类复核、确定性计算、对账、任务状态和固定模板 Excel 导出。 |
| Agent preset 与依赖检查 | 待开发的智能体组合包 | 尚未发布 | 在执行前检查必需技能和业务能力，并把缺失项转为准确的用户提示。 |

其他现有员工技能不是首版必需依赖。普通企业数据查询不能代替专用分析能力，也不能用来拼装含薪资的正式 Excel。

### 缺失依赖时的处理

正式 Agent preset 启动时先核对技能是否可发现、提供技能的工作台插件是否已安装并启用，以及人力分析专用能力是否可用。检查失败时停止分析，不生成文件，并按已确认的原因提示用户：

| 核对结果 | 给用户的提示 |
| --- | --- |
| 工作台插件未安装 | 「缺少元枢工作台插件。请安装并启用后再使用人力投入分析。」 |
| 工作台插件已安装，但员工连接或技能未启用 | 「元枢工作台已安装，但人力投入分析技能尚不可用。请启用员工连接，或更新工作台插件后重试。」 |
| 技能可用，但人力分析专用插件未安装，且该插件已发布 | 「缺少人力分析插件。请安装并启用后再生成 Excel。」 |
| 专用插件尚未发布 | 「人力分析所需的计算与 Excel 导出能力尚未发布，目前无法生成正式文件。」 |
| 插件已安装但能力检查失败 | 「人力分析能力暂时不可用。请检查插件状态，恢复后重试。」 |
| 插件与技能齐备，但当前账号未获授权 | 「当前账号没有所选范围的人力分析或导出权限。请联系管理员核对授权。」 |

不能仅凭技能缺失就断言插件未安装；也不能把授权拒绝、连接失效或后台数据缺口解释为安装问题。若运行端无法确定具体原因，报告「依赖状态暂时无法确认」，由工作台记录诊断，避免给出错误的安装指引。

## 分工与边界

| 部分 | 职责与边界 |
| --- | --- |
| 智能体 | 理解请求、核对范围、编排取数与复核、提出有依据的分类和文字建议、检查任务状态；不能自行确定薪资口径或改动模板字段。 |
| 员工技能 | [人力投入分析](../../skills/yuanshu-hr-analysis/SKILL.md)描述员工可见流程、人工确认点、完成与失败状态；不携带后台连接逻辑。 |
| 工作台与后端 | 按租户、员工、动作和数据范围验权；提供有界数据快照、确定性计算、对账、任务恢复、审计和 Excel 导出。专用分析能力尚待开发；现有普通只读查询不能充当它。 |
| 人工复核 | 获授权的复核人处理低置信度分类、缺口、工时调整与规则冲突，并记录结论、理由、操作者和时间；未完成必审项时停止正式导出。 |

只采集获授权的工作数据，不采集在线时长、屏幕行为、聊天内容或位置。分析用于工作量与流程改进；个人绩效评价须另行授权。含个人薪酬、时薪或可反推时薪的完整 Excel 仅交付获授权的人力组人员。部门负责人、管理层和员工本人的其他视图需独立的权限与模板版本，不能由完整文件删列生成。

首版不创建 A2UI 报告界面、预览文件、飞书文档或单独的图表产物。原始需求中的自动月报推送、群告警和自然语言切片问答属于后续能力；任务失败时仍须反馈状态与原因。数据源为空、授权无法确认、覆盖或对账不合格、任务结果未知时，不宣称生成成功；重试前先查询原任务状态，防止重复导出。

## 验收基准

同一数据快照和规则版本重复运行，工作表结构与数值一致；跨月周窗口、缺报、人工调整、权限拒绝、失败恢复及敏感字段隔离均通过检查。用原需求 2026 年 7 至 10 月的六项历史目标回归，具体目标和容差见[Excel 输出内容定义](../../skills/yuanshu-hr-analysis/references/输出内容定义.md)。原始需求中的 2026 年 11 月人资工作结构样张用于核对九类工作项和产出依据。业务分类和未定口径需由人力组确认后才能作为正式验收依据。
