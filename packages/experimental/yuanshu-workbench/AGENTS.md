# 元枢工作台开发规则

本目录适用于元枢工作台插件、业务表单、随包技能与业务智能体。全局编码约束见 [工作区编码规则](../../../../CODING_RULES.md)，员工技能规则见 [skills/AGENTS.md](skills/AGENTS.md)，智能体开发规则见 [agents/AGENTS.md](agents/AGENTS.md)。

## 对话业务新增

- 对话新增从后台发布的服务目录获取业务名称、别名、动作、可写字段、权限映射和回执约定。工作台源码与随包配置不得登记具体业务的兼容映射。接口契约更新后随目录刷新生效。
- 接口已发布但暂时无法生成表单时，保留目录查询结果并说明缺项。打开和保存表单时继续核对员工权限，保存由本人确认。

## 数据字段和枚举

- 表单字段必须对应当前有效数据库结构中的列，并核对对应中文备注及服务端 API 契约。
- 下拉项的存储值和显示含义必须逐项来自当前字段约束、数据库注释或正式 API 契约；只翻译显示文案，保留原存储值。
- 字段备注以「值=含义」列出固定枚举时，编辑表单默认使用下拉框，中文界面显示中文含义，提交保留原值及类型。对话与导入只预选能唯一匹配的值，无法匹配的值由用户纠正。
- 不得自行增加数据库/API 未定义的字段、枚举、状态含义或默认值。已删除表列和历史迁移只能用于追溯，不代表当前有效契约。
- 如果数据库、字段备注和 API 契约缺少表单必需定义，先核实并补齐正式契约，再实现界面；不得用模型推测补值。
- 保存、提交等人工确认表单必须等待服务端操作完成并收到可验证的成功回执后才关闭。失败时保留弹窗和用户输入，显示清楚的错误；结果不确定时只能使用幂等的安全重试，不得误报成功。
