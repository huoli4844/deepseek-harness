# @deepseek-ai/dsh-client-yuanshu-workbench

[English](README.md) | 中文

## 概述

此组合包在 DSH Web 中打开适配岗位的助理收件页，汇总岗位关注、任务与日程并提供直达操作。岗位工作台提供图表；项目管理岗位另有项目运营台，将项目组合健康度、变化、依赖、风险、决策、行动和验收门禁串联起来。18 个岗位和公司管理层各有 4 个 KPI 关联场景与 3 项连接工作方法的日常任务。工作群用于项目、督办和专题沟通，可邀请岗位助理并保留浏览器本地历史。 仪表板使用保存在浏览器中的演示记录。配置员工 MCP 后，DSH 原生助理可以发现获准使用的元枢工具。

<a id="use-this-package"></a>
## 使用此包

### 连接员工账号

在单账号 DSH Host 的 `yuanshu-workbench` 插件条目配置 `mcp.url` 和 `mcp.clientId`。在元枢注册 DSH 的准确来源地址加 `/mcp/oauth/callback/56a411dab576919cbca52fcfee03f1a34ff9b37d4858c71c781c9005942ac59f` 作为回调，并在元枢的 `client_mcp.preauthorized_clients` 中按租户 ID 加入该客户端 ID。打开插件页 → 元枢工作台 → 登录元枢。浏览器登录成功后，获预授权的客户端直接取得读取权限。其他客户端继续走显式同意流程。当前授权页只支持无需额外完成 MFA 或验证码挑战的登录。

连接模式下，「今日工作」和「我的任务」读取待办与风险，「岗位工作台」显示简报指标，「项目运营」显示项目，「日程日历」显示项目里程碑，「经营重点」显示待决策事项，「工作方法」显示岗位流程。工作群、消息通知和文件与资料在接入平台数据源前显示未接入提示。

### 从当前检出目录预览

构建当前检出版本后，在 `dev` 分支的仓库根目录启动 Web profile。源码启动器先加入工作台组合包，再应用你的 Web profile 补丁。

```sh
pnpm run build
pnpm dsh web
```

打开 DSH 输出的本地入口地址。插件加载后进入**元枢工作台**的**今日工作**页，仅显示工作台自己的导航和内容。收件页汇集岗位关注、本人任务和日程；**岗位工作台**用于查看图表和比较。通过工作台底部按钮返回 DSH 原始界面，当前会话保持选中。演示记录保存在当前浏览器 profile 中，页面刷新或插件重新加载后仍会保留；清除站点数据会删除这些记录。

### 可体验的功能

在项目运营页展开 ECN-204，点击「准备 DSH 分析草稿」。演示资料和补充约束会加入当前或最近工作区的新会话草稿。检查草稿后即可发送，标准 DSH 会话会显示实际创建的子智能体。

在 **项目经理 → 今日工作** 中打开延期预警，演练 MS-017：生成模拟分析、批准建议方案、模拟派发、验收模拟回执。关闭后可在跟踪区回看决策记录。预警、证据编号和允许的状态转换由里程碑模拟模块提供；接入平台时改用经过授权的读取接口与业务命令。

- 普通岗位提供 6 张图表，公司管理层与特种车业务总裁提供 8 张：趋势、进度、业务分布、计划对比、每周完成量和风险矩阵；管理层另含回款和资源覆盖率。新增图表可打开数据明细并进入关联任务。
- 切换全部 19 个岗位视角：助理收件页和岗位图表会随岗位适配，公共导航始终可用。公司管理层与特种车业务总裁可从风险汇总进入责任岗位。
- 查看公司重点事项的演示值、来源、责任岗位和下一步行动；默认显示当前岗位承担的事项，也可切换到公司清单并进入对应 KPI 工作流。
- 启动本地助理流程演示：查看四步计划、来源与 KPI 依据、跨岗位复核、可编辑建议和人工确认；确认后只更新关联的浏览器本地演示工作项。
- 在浏览器 profile 中保存岗位专属的助理偏好，并在每次运行时与方法、来源依据和拟议行动并列查看。
- 打开岗位的任一 KPI 关联场景，助理会进入其典型工作，套用对应岗位方法并准备待复核草稿；每个岗位另有 3 项高频工作场景，以可视四步 SOP 流程呈现并可直接交由助理协同开展。
- 「今日工作」先呈现助理建议优先处理的事项及原因，再列出其他待决定、待复核和收到的交付。操作可直达对应 SOP、群内交付要求或具体项目记录。展开常用工作场景可查看启动条件和交付要求。等待协作、已完成记录及 KPI 场景可在下方查看。
- 从「今日工作」继续上次的工作：切换页面或刷新当前浏览器 profile 后，仍可恢复岗位视角、SOP 步骤、草稿材料和交接摘要。
- 全部 57 项岗位工作配置建议方法，以及各自的材料、交付物和验收关注点。材料、分析、成果和审阅阶段内嵌方法指导、证据记录与自查项；版本保存方法执行快照。方法库直接打开对应任务。
- 打开任务、编辑建议、保存版本，并从任务内打开版本历史、比较快照、采纳预设建议和模拟审阅交接。
- 选择日历日期并添加本地日程；切换岗位后，日程和消息已读状态仍保留。
- 创建项目沟通、工作督办或专题讨论群，邀请岗位助理，发布工作安排、发送本地消息并回看群历史。受派岗位先提交交付记录，再由工作负责人打开关联任务复核。助理回复为脚本演示。
- 打开项目运营台选择项目，检查关联里程碑和依赖，查看带证据的变化与风险，记录决策方案，完成责任行动，并在必要行动验证后提交验收。
- 从助理提醒或岗位工作台进入岗位运营。其余 17 个岗位及公司管理层各有业务来源、指标对比、两种处置方案及关联 SOP。确认方案后创建工作群派单，切换至交付岗位可在助理待办中提交证据，再切回发起岗位按场景标准退回补充或记录验收。群内保留派单、证据与复核记录。
- 在文件与资料页查看演示材料，并在工作群分别跟踪任务安排、岗位交付和负责人复核。

## 模型体验

无，因为工作台仅展示本地演示记录及预设建议，不提供工具、提示词或会话事件。

#### KV 缓存影响

工作台导航与草稿编辑不改变模型请求及其缓存。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 岗位选择仅演示界面适配，不授予身份或业务权限。公司管理层是额外演示视角，没有在平台岗位表中新增岗位；项目管理尚未配置 KPI，其图表仅展示演示进度。
- 图表数值、资料和日程日期均为合成演示内容，不是已确认的 KPI 公式或实时经营结果。
- 交接和通知仅在本地模拟，不发送外部消息，也不创建平台任务或审批。工作群成员、安排和聊天记录保存在当前浏览器 profile。
- 助理计划、岗位交付记录和审批结果均为脚本演示，不调用模型或 MCP 工具；交付不会创建或更新平台数据。
- 岗位偏好是浏览器本地的原型上下文，不会发送给模型或元枢平台。
- 16 种建议方法需经业务确认后才能成为正式规程。自查只记录用户确认；未完成的事项可携带可见缺口提交协同审阅，不会自动通过审批。
- 演示记录仅保存在当前浏览器 profile，不会跨设备同步，也不是元枢业务记录。元枢 MCP 集成与业务状态持久化不属于此原型范围。

### 开发备注

<details>
<summary>维护者工作上下文——点击展开</summary>

此包是 `dev` 分支上的实验性插件原型，用于在平台集成前评审界面。

启用真实「今日工作」时，为工作台 MCP 配置员工端点、OAuth 客户端 ID 和平台认证地址（`apiUrl`）。Host 核实当前登录员工和租户后读取工作台数据。只有已验证的员工与租户 ID 会保留到 profile 过期或 MCP 连接代次变化；每次工作台投影仍由元枢授权。在元枢的 `client_mcp.preauthorized_clients` 中为需要自动连接的租户登记 DSH 客户端。登录后打开「今日工作」时，DSH 会为所选租户申请只读授权。

在元枢 OAuth 客户端登记 DSH 的完整回调地址。Host 对外地址为 `http://127.0.0.1:3080` 时，回调地址是 `http://127.0.0.1:3080/mcp/oauth/callback/56a411dab576919cbca52fcfee03f1a34ff9b37d4858c71c781c9005942ac59f`。
