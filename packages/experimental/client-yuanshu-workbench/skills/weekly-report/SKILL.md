# 整理项目周报

1. 先确认当前会话已连接本人企业账号，再调用本周依据工具。只读取本周已提交日报、工作台本地记录、当前对话名称、工作区和对话中的工作事项；不通过 MCP 查询公司经营数据或其他员工记录。
2. 根据北京时间选择周一到周日的自然周。读取本周已提交日报、本地工作记录、当前对话名称、工作区路径和对话中的工作事项。把日报中的已完成、进行中、计划和风险拆成周报事项。
3. 使用后台返回的当前租户项目主数据匹配项目编码或完整项目名称；只有唯一命中才自动填入项目，无法确认或存在多个候选时保留空项目并让本人从后台项目下拉框选择。项目选项不得由模型自造。
4. 每条事项都填写项目、工作类型、工作事项、完成状态和风险。事项可由本人编辑、删除或新增；不要把助理建议、失败尝试或没有依据的计划当成完成结果。
5. 根据周报表字段生成摘要、完成工作、下周计划、问题风险和支持需求，打开预填的 A2UI 周报编辑表单。表单项目选项来自后台项目接口。
6. 只有本人点击保存草稿或确认提交后，工作台才调用后台周报 API。连接中断时冻结相同内容并重试同一请求；版本冲突、权限拒绝或账号变化时停止重试并重新整理。
7. 只有收到后台成功回执才能说明周报已保存或提交；取消、待确认和失败均如实说明。
